## Nithisha Venkatesh

AI engineer. I build LLM systems (RAG, multi-agent setups, guardrails) and spend most of my time on what happens after the demo works.

### Work I'm proud of

**[Athenaeum](https://github.com/NithishaVenkatesh/athenaeum-multi-agent-system)**  
A multi-agent tutor that won the global student award at Microsoft's Agents League. Every answer is cited, and you can open a trace to see which model answered, how sure it was, and where the answer came from. The safety layer was tested against 232 attack prompts and blocked every direct one.

**[wolff](https://github.com/NithishaVenkatesh/wolff)**  
Quote-to-cash for freelancers and agencies: quote, e-signature, GST invoice, payment. Open source, 2,800+ tests, runs entirely on free tiers. I wrote about half of its 700 commits.

**[Nucleus AI](https://github.com/NithishaVenkatesh/Nucleus-AI)**  
Answers questions over a company's Confluence with the sources attached. Hybrid retrieval and reranking to find the right pages, and an NLI check that throws out answers contradicting the documents they cite.

**[Gappy](https://github.com/theCodeForgerHQ/Gappy)**  
An agent that fixes bugs in Python repos, but it doesn't decide when it's done. A failing test you wrote has to pass, and a second agent reviews the diff to make sure it didn't just weaken the test. Won the Gappy AI hackathon.

### How I work

- I write down how a system should fail before I write how it should work. Retries, fallbacks and timeouts are part of the design, not a patch.
- Every number in my READMEs came from a run I can reproduce.
- I'd rather ship something narrow that works than something broad that demos well.
